## 💡 1. 연구 한눈에 보기 (Executive Summary)

### 이 연구는 무엇을 해결하려는 것인가요?
응급실 중증도 분류 도구(KTAS)는 원래 사람이 종이/전자 매뉴얼을 보며 위에서 아래로 훑도록 만들어진 **평면 나열형 규칙 목록(`T_orig`)**입니다.  
이 구조를 그대로 LLM(거대 언어모델)에 입력하면 두 가지 문제가 생깁니다:
1. **불필요한 중복과 토큰 낭비**: 하나의 주호소 안에서도 `"1차 활력징후"`, `"통증 척도"`, `"혈압"`, `"출혈"` 같은 동일한 임상 변수가 1~5등급에 걸쳐 수차례 반복 등장합니다.
2. **비정형 응급실 기록에서의 주의 분산**: 실제 응급실 간호사 초진 기록처럼 구어체·배경 잡음(Distractor)이 섞인 긴 텍스트가 들어오면, LLM이 20여 줄짜리 평면 규칙을 훑다가 **필수 1차 활력징후 확인을 건너뛰거나 중증 환자를 경증으로 과소평가(Under-triage)**하는 치명적 오류가 발생합니다.

### 우리가 제안한 해법과 핵심 성과
* **해법 (`T_opt`)**: 기존 KTAS의 임상 판정 기준을 단 한 글자도 바꾸지 않고(**100% 논리적 동치**),  
  **① 예외 게이트(DNR 등) 최우선 분리 ➔ ② 1차 공통 축 Single-Pass 통합 ➔ ③ 2차 조건 임상 변수별 그룹화** 구조로 결정 트리를 리팩토링했습니다.
* **핵심 실측 결과**:
  1. **무결점 기준 트리(Ground Truth) 확보**: 공식 PDF(398p)와 JSON을 전수 대조해 소아 1차 누락 4개 축, 소아 등급 오류 8건, 누락 주호소(`611`)를 모두 복원해 **PDF 318개 주호소 100% 매칭 / 등급 불일치 0건**을 달성했습니다.
  2. **100% 논리적 동치성 입증**: 전체 326개 주호소 · **87,046건**의 입력 조합 전수 시뮬레이션에서 **$T_{\text{orig}}(x) \equiv T_{\text{opt}}(x)$ 100.0000% 일치(불일치 0건)**를 증명했습니다.
  3. **토큰 효율 대폭 개선**: 실제 LLM 추론 시 환자 1건당 총 토큰 수를 **정형 N=300에서 `-21.0%`($p = 6.09 \times 10^{-50}$)**, **노이즈 N=40에서 `-19.3%`($p = 5.21 \times 10^{-8}$)** 절감했습니다.
  4. **현실적인 비정형 노이즈 환경(N=40)에서의 압도적 역전**:
     * 정형 키워드 입력(N=300)에서는 `T_orig`의 `1➔5` 수직 나열이 유리했으나(`97.33%` vs `92.67%`),
     * 실제 응급실 초진 기록 같은 **비정형 노이즈 환경(N=40)**에서는 `T_orig`의 정확도가 **82.50%(Hotspot 80.00%)**로 급락한 반면, **`T_opt`는 92.50%(Hotspot 96.00%, +16.00%p)**를 유지하고 **핵심 1차 활력징후 누락률을 28.57% ➔ 5.71%($p = 0.0078$)**, **치명적 과소평가율을 절반(10.00% ➔ 5.00%)**으로 낮췄습니다.

## 🎯 2. 연구 목표 및 3대 엄격한 제약 조건

1. **100% 논리적 동치성 보장 ($T_{\text{orig}}(x) \equiv T_{\text{opt}}(x)$)**:
   * 모든 유효 입력 조합에 대해 원본 트리와 최적화 트리의 최종 KTAS 등급(1~5등급)이 단 한 건도 달라져서는 안 됩니다.
2. **임상 판정 기준 불변**:
   * KTAS의 의학적 기준 수치(혈압, SpO2, 체온, 통증 점수, 연령대 경계 등)는 임의로 변경하거나 AI의 추정으로 임의 병합하지 않습니다.
3. **선후행 의존성 및 `Don't-Care(*)` 경로 보존**:
   * 성인(`>=15세`) / 소아(`<15세` 및 세부 월령) 컨텍스트를 엄격히 분리하고, 대분류(계통) ➔ 주호소 ➔ 예외 게이트(DNR) ➔ 1차/2차 평가의 선후행 의존성을 해치지 않습니다.

#### Step 2-3. 최적화 트리(`T_opt`) 생성 및 100% 논리적 동치성 검증 (`reports/optimization_summary.md`)
* **설계된 `T_opt` 구조 (`data/optimized/ktas_optimized_tree.json`)**:
  ```text
  [주호소 진입]
     ├─ 1. 예외 게이트 (exception_gates: 심정지 DNR 등 최우선 단락 평가)
     ├─ 2. 1차 공통 축 Single-Pass (1차_활력징후 / 통증_척도 / 출혈_양상 / 고위험_사고기전 축별 통합)
     └─ 3. 2차 변수 그룹 (second_order_variable_groups: 임상 변수별 묶음, 그룹 내 1->5등급 정렬 + 가지치기)
     ➔ 최종 등급 = 예외 게이트 매칭 시 해당 등급, 아니면 min(1차 Single-Pass, 2차 변수 그룹)
  ```
* **100% 논리적 동치성 전수 검증 (`verify_equivalence.py`)**:
  * 전체 **326개 주호소**, 총 **87,046건**의 입력 조합(원자 명제 ≤ 10개는 $2^m$ 전수 진리표, 초과 시 1-hot·2-hot·경계·무작위 커버리지)을 실행해 **$T_{\text{orig}}(x) \equiv T_{\text{opt}}(x)$ 100.0000% 일치(불일치 0건)**를 입증했습니다.
* **정적 구조 및 직렬화 토큰 개선**:

## 🧠 5. 핵심 연구적 발견 및 메커니즘 해석

### 발견 ①: "수학적 논리 동치 $\neq$ LLM 행동적 동치" (정형 N=300 분석)
* 파이썬 엔진에서는 87,046건 전수 테스트에서 **100.0000% 동치**였던 `T_opt`가, 정형 입력 N=300에서 `T_orig` 대비 정확도가 `-4.67%p` 낮아진 이유를 오분류 18건 분석으로 규명했습니다.
* **원인 (Recency Bias & 수직 단락 붕괴)**:
  * `T_orig`는 `1단계 ➔ 2단계 ➔ 3단계 ➔ 4단계 ➔ 5단계`로 수직 정렬되어 있어, LLM이 위에서부터 읽다 중증 키워드에 매칭되면 자연스럽게 멈춥니다.
  * 반면 `T_opt`는 `[2. 1차 공통 축]` 뒤에 `[3. 2차 변수 그룹]`을 배치하고, 한 변수 줄 안에 `2단계 / 4단계 / 5단계`를 가로로 병기했습니다. 이로 인해 `EVAL_GEN_081`(1차 활력징후 1단계 + 2차 국소성 발진 5단계)처럼 **앞쪽 1차 축에서 1단계를 찾고도 뒤쪽 2차 그룹의 5단계 문구를 읽고 덮어쓰는 Recency Bias**가 발생했습니다.

### 발견 ②: "현실적 비정형 노이즈 환경에서는 `T_opt`가 압도적 우위" (노이즈 N=40 분석)
* 실제 응급실 초진 기록처럼 구어체·배경 잡음·간접 묘사가 들어가면 정반대의 현상이 나타났습니다:
  * `T_orig`는 19줄짜리 `적용 가능 1차 고려사항`과 최대 21줄짜리 평면 2차 리스트가 노이즈 텍스트와 뒤섞이면서, LLM이 **핵심 1차 활력징후를 28.57%나 건너뛰고(누락)** Hotspot 주호소 정확도가 **80.00%(Macro-F1 65.89%)**로 급락했습니다.
  * 반면 `T_opt`는 **1차 공통 축 Single-Pass 구조**가 모델의 주의를 고정해 주어 **핵심 1차 활력징후 누락률을 5.71%($p=0.0078$)**로 방어했고, **Hotspot 정확도 96.00%(+16.00%p)**, **치명적 과소평가율 절반 감소(10% ➔ 5%)**, **총 토큰 -19.3% 절감**을 동시에 달성했습니다.

## 🔜 6. 향후 실험 계획 (Phase 4 제안)

1. **Plan A — Hybrid `T_opt-v2` (Recency Bias 제거 + 노이즈 강건성 결합)**
   * **아이디어**: `T_opt`의 장점인 **1차 공통 축 Single-Pass**와 **변수 그룹화**는 그대로 유지하되, 출력 직렬화 시 **중증도 우선 수직 계층(예: `[긴급 게이트: 1~2등급 1차+2차 변수 그룹]` ➔ `[응급/경증: 3~5등급 변수 그룹]`)**으로 상·하단을 분리해 Recency Bias를 원천 차단.
