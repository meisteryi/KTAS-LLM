## 1. 왜 이 연구를 시작했나요? (해결하려는 문제)

### 🏥 실제 응급실에서 벌어지는 일
환자들은 의사 앞에서 교과서처럼 깔끔하게 말하지 않습니다:
> *"선생님, 제가 비 올 때마다 왼쪽 무릎이 쑤시는데요... 근데 사실 1시간 전부터 갑자기 혀가 굳어서 말이 꼬여요."*

* **기존 일반 챗봇(AI)의 치명적인 약점**:
  * AI는 보통 문장 앞쪽에 나온 **"비 올 때마다 무릎이 쑤신다"**는 말에 꽂혀서, 환자를 덜 위급한 **KTAS 5단계(비응급)**로 분류해 버리는 실수를 저지릅니다.
  * 하지만 뒤에 나온 "혀가 굳어 말이 꼬인다"는 **뇌졸중(중풍) 골든타임 징후로 당장 2단계(긴급) 처치가 필요한 위급 상황**입니다! 잘못 분류하면 환자가 목숨을 잃을 수 있습니다.

### 🎯 우리 연구의 해결책
환자가 어떤 순서로 말을 뒤섞든, **"가장 위험한 치명적 증상에 먼저 반응하여 올바른 등급을 매기고, 의학적으로 타당한 이유를 말해주는 AI"**를 만들었습니다.

## 2. 데이터를 어떻게 준비했나요?

### 📚 1) 학습용 데이터: 3,600건 (Train 3,240건 + Val 360건)
* 응급실에 자주 실려오는 **25가지 핵심 질환(뇌졸중, 심근경색, 호흡곤란, 대량출혈 등)**에 대해 실제 환자들이 쓸 법한 자연스러운 구어체 대화를 구성했습니다.
* AI가 출력할 때는 단순히 "2단계입니다"로 끝나는 게 아니라, 아래처럼 **정확한 공식 룰 번호와 의학적 이유(Rationale)**를 JSON 형식으로 깔끔하게 내놓도록 훈련했습니다:
  ```json
  {
    "primary_complaint": "급성 신경학적 결손",
    "applied_rule_id": "신경계_409_2차고려_발병24시간이내",
    "rationale": "발병 24시간 이내에 발생한 급성 언어장애는 뇌졸중 골든타임 증상이므로 2단계 긴급에 해당함.",
    "ktas_level": 2
  }
  ```

### 🔬 2) 시험용 벤치마크: "4가지로 말 바꿔보기" (4-way 스트레스 테스트)
단순히 몇 문제 맞혔나만 보면 AI가 찍어서 맞힌 건지 알 수 없습니다. 그래서 **1개 환자 증례마다 말을 4가지 방식으로 비틀어서 총 600번의 시험**을 치렀습니다:

| 시험 유형 | 환자가 실제로 한 말 (예시) | 기대하는 정답 | 검증하려는 능력 |
| :--- | :--- | :---: | :--- |
| **① 원래대로 말하기 (A+B)** | *"가슴이 찢어지듯 아파요(응급). 근데 원래 무릎도 쑤셔요(만성)."* | **2단계 (긴급)** | 기본 문진 상태에서의 정답 |
| **② 순서 바꿔 말하기 (B+A)** | *"원래 무릎이 쑤셔요(만성). 근데 갑자기 가슴이 찢어지듯 아파요(응급)."* | **2단계 (긴급)** | **순서 불변성**: 사소한 무릎 통증을 먼저 말했다고 해서 속지 않는가? |
| **③ 위험 증상 빼기 (B만)** | *"원래 비 올 때마다 쑤시던 무릎이 오늘도 좀 욱신거려요."* | **5단계 (비응급)** | **인과 민감도**: 위험한 흉통이 사라졌으니 등급을 정상적으로 낮춰주는가? |
| **④ 사소한 증상 빼기 (A만)** | *"갑자기 가슴 한복판이 찢어지는 것처럼 아프고 식은땀이 나요."* | **2단계 (긴급)** | **잡음 견고성**: 사소한 잡음이 빠져도 원래의 2단계를 굳건히 지키는가? |

* **미학습 질환(OOD) 50건 포함**:
  * 특히 시험 문제 중 50건은 AI가 **학습할 때 한 번도 본 적 없는 질환(천식 발작, 벌 쏘임 아나필락시스 쇼크, 폐색전증 등)**으로만 구성했습니다.
  * AI가 문장을 외운 게 아니라, **처음 보는 병 앞에서도 진짜 의사처럼 응급도를 판별할 수 있는지**를 테스트하기 위함입니다.

## 3. 모델 학습은 어떻게 진행되었나요? (LoRA 파인튜닝)

* **베이스 모델**: Qwen2.5-32B (파라미터 320억 개, 무게 62GB의 매우 똑똑한 거대 모델)
* **LoRA(로라) 기술 적용**:
  * 320억 개짜리 거대한 원본 두뇌는 **단 1비트도 손대지 않고 100% 잠금(Read-Only)** 상태로 두었습니다.
  * 대신 전체의 **0.08%(약 2,500만 개)에 해당하는 아주 얇고 가벼운 '응급실 전용 메모지(어댑터)'**만 붙여서 학습시켰습니다.
  * 장점: 원본 모델의 뛰어난 언어 능력이 망가지지 않고, 나중에 마음에 안 들면 메모지만 떼어내면 되므로 매우 안전합니다.

## 5. 최종 시험 성적표 (그래프로 쉽게 보기)

기존 기본 모델(Zero-Shot)과 힌트를 조금 준 모델(Few-Shot), 그리고 **우리가 훈련시킨 모델(LoRA SFT)**의 성적을 비교했습니다.

| 시험 지표 (무엇을 보나요?) | 기본 모델 (Zero-Shot) | 힌트 준 모델 (Few-Shot) | **우리 모델 (LoRA SFT)** |
| :--- | :---: | :---: | :---: |
| **룰 정답률 (DRA)**: 단계와 규칙 번호를 모두 맞힌 비율 | 58.2% | 74.5% | **95.5% (압도적 1위)** |
| **순서 불변성 (OIR)**: 말하는 순서를 바꿔도 안 속는 비율 | 62.4% | 78.1% | **99.0% (거의 완벽)** |
| **인과 민감도 (CSR-Down)**: 위험 증상이 빠지면 등급을 낮추는 비율 | 71.0% | 82.3% | **97.2% (매우 민감)** |
| **잡음 견고성 (CSR-M)**: 사소한 증상이 빠져도 등급을 지키는 비율 | 68.5% | 80.0% | **98.0% (흔들림 없음)** |
| **이유 정합도 (RTAS)**: 의학적으로 타당한 이유를 설명한 비율 | 54.0% | 71.2% | **96.5% (의사 수준 이유)** |

## 6. 자주 묻는 질문 (교수님 질문 대비 Q&A)

### Q1. "데이터 150증례(600개 발화)나 25개 질환은 너무 적은 거 아닌가요?"
* **답변**:
  1. **의료 저널 표준**: JAMA나 Lancet 등 세계적인 의학 AI 논문에서도 전문의가 100% 검증한 임상 증례는 보통 100~300건을 표준으로 삼습니다. 노이즈 많은 인터넷 글 10만 개보다 정밀 검증된 수백 개가 훨씬 신뢰성이 높습니다.
  2. **핵심 85% 커버**: 25종 질환은 임의로 고른 게 아니라, 실제 응급실에 실려오는 **중증/사망 고위험 환자의 85% 이상을 차지하는 핵심 질환**입니다.
  3. **이미 똑똑한 AI**: 우리는 AI에게 말을 처음부터 가르친 게 아니라, 이미 똑똑한 320억 개 두뇌에게 **"응급실 규칙을 엄격하게 지키는 법"**만 가르쳤기 때문에 수만 개 데이터가 필요하지 않습니다.
  4. **언제든 10배 확장 가능**: 데이터 생성 코드가 완전히 자동화되어 있어, 교수님께서 원하시면 언제든 50종 질환, 1,000개 증례로 며칠 안에 늘릴 수 있는 준비가 되어 있습니다!

### Q2. "모델 가중치가 오염되거나 망가질 위험은 없나요?"
* **답변**:
  * 원본 62GB 모델은 **읽기 전용(Read-Only)으로 100% 잠가두고**, 바깥에 **0.08%짜리 얇은 LoRA 메모지 어댑터**만 붙여서 학습했습니다. 원본 두뇌는 전혀 손상되지 않았으며 안전합니다.
